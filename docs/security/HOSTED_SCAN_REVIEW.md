## Runtime inventory

The Alpine image passed actual container MFA/device binding, encrypted file exchange, policy revocation and evidence verification. Trivy then reported two HIGH findings for `libcrypto3` and `libssl3` at `3.5.7-r0`, CVE-2026-14456; its fixed version was `3.5.8-r0`. Both system packages are explicitly upgraded to the official Alpine v3.24 package version `3.5.9-r0`. The final image must be rebuilt and rescanned.

Node also bundles its own OpenSSL. Updating Alpine packages does not update that copy. Native Node 24.19.0 reports OpenSSL 3.5.7, `node_shared_openssl: false` and `node_use_quic: false`; CI checks these properties inside the final container too. The [OpenSSL advisory](https://openssl-library.org/news/secadv/20260813.txt) identifies a QUIC incoming-channel queue issue. This application's HTTP stack does not use QUIC. The system-package scan is therefore not a comprehensive claim about every bundled runtime component or every vulnerability. Monitor Node security releases separately and revalidate pinned updates.
