# Execution checklist for both implementation briefs

This maps every numbered section of the two user-supplied implementation briefs to actual repository work. It is an evidence ledger, not a blanket completion claim. **TESTED/EXECUTED** means the stated local scope was run; **PARTIAL** identifies missing or external work. Actual hosted CI, scanner and release results must be checked for the final commit. No production-readiness or certification claim is made.

Paths below are repository-relative. Start with [implementation status](IMPLEMENTATION_STATUS.md), [test evidence](hpsc/evidence-index.md) and [limitations](limitations.md). The original attachments are not published here.

Remain explicit about failed jobs, unexecuted scans, missing operational controls and external approval gates.
