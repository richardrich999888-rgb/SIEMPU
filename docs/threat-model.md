# Threat model entry point

The maintained [threat ledger](threat-model/README.md) defines assets, adversaries, trust boundaries, 21 attack classes, controls and residual risks. Its four mandatory abuse cases map to the actual negative and race tests in [traceability](TRACEABILITY_MATRIX.md). Implemented controls are summarized in [security](security.md); observed defects and regressions are in the [security regression log](security/SECURITY_REGRESSION_LOG.md). A threat-model document is not independent security certification.
