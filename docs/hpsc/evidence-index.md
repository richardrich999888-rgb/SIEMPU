## Native release gate

`npm run validate` produces `artifacts/validation/report.json` plus per-gate logs, including `artifacts/validation/test-coverage.log`. Add `-- --benchmark` to run the optional benchmark, whose output is isolated in `artifacts/validation/benchmark/results.json`. [Claim audit](../../scripts/audit-claims.mjs) requires the report to match the current source digest, mandatory passing gates, test counts and completed demo stages. Use a fresh execution report for current counts and the exact commit's Actions results for hosted outcomes. The native report deliberately does not assert external browser/container/hosted SAST execution.
